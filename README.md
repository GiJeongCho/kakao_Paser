# 카카오톡 메시지 정리 (KakaoParser)

카카오톡 대화를 붙여넣으면 시간·이모지·특수문자를 정리해서 깔끔한 텍스트로 바꿔주는 도구.

## 변환 예시

**입력**
```
[🟢제이/하남/45] [오후 2:39] 네 그 가격보다는 높게 쓰셔야 합니다.
채권자는 일부러 낙찰가를 높게 하기 위해서 우선 매수를 신청하는 경우도 있지요..
[❤️그레포레/용인/38] [오후 3:10] 감사합니다!
```

**출력**
```
[제이] 네 그 가격보다는 높게 쓰셔야 합니다.
채권자는 일부러 낙찰가를 높게 하기 위해서 우선 매수를 신청하는 경우도 있지요..
[그레포레] 감사합니다!
```

## 기능

- 시간 제거 (`[오후 2:39]` 등)
- 이름 정리 — 이모지·특수문자 제거, `/` 뒤 지역·나이 제거
- 본문 내 @멘션도 같은 규칙으로 정리
- 같은 사람이 연속으로 말하면 하나로 묶기
- `메시지가 삭제되었습니다.`, 빈 줄, 구분선(`====`) 자동 제거
- 입력 즉시 실시간 변환 + 결과 클립보드 복사 버튼

## 사용법

### 브라우저에서 바로 사용
`index.html`을 더블클릭하면 브라우저에서 열림.

### 데스크톱 앱 (.exe)
`dist/카카오톡메시지정리.exe` — 설치 없이 더블클릭으로 실행되는 포터블 exe.

## 빌드

```bash
npm install
npm run dist
```

`dist/` 폴더에 포터블 exe가 생성됨.
