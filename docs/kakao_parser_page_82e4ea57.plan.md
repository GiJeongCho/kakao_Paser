# 카카오톡 메시지 정리 페이지

## 목표
입력 textarea에 카카오톡 대화를 붙여넣으면, 변환된 텍스트를 실시간으로 보여주는 단일 페이지를 만든다.

## 생성 파일
- `c:\project\kakao_Parser\index.html` (HTML + CSS + JS 한 파일, 기존 프로젝트들과 동일한 순수 정적 페이지 방식)

## 입력 형식 가정
카카오톡 복사 시 각 메시지는 다음 형태로 시작한다.
```
[🟢고지마제이/하남/45] [오후 2:39] 네 그 가격보다는 높게 쓰셔야 합니다.
일부러 낙찰가를 높게 하기 위해서...   <- 다음 줄(접두사 없음)은 이전 메시지의 연속
```

## 변환 규칙 (JS)
- **메시지 시작 줄 인식**: 정규식 `^\[([^\]]*)\]\s*\[[^\]]*\d{1,2}:\d{2}[^\]]*\]\s*(.*)$`
  - 1번 그룹 = 이름, 시간 대괄호(`:` 포함)는 버림, 2번 그룹 = 본문
- **이름 정리** `cleanName(raw)`:
  - 첫 `/` 앞부분만 사용: `raw.split('/')[0]`
  - 이모지/특수문자 제거: 한글·영문·숫자만 남김 (예: `🟢고지마제이/하남/45` → `고지마제이`)
- **멘션 정리**: 본문 내 `@(\S+)` 를 찾아 동일한 `cleanName` 적용 (예: `@🟢고지마제이/하남/45` → `@고지마제이`)
- **연속 줄 처리**: 시작 줄이 아닌 줄은 직전 메시지 본문에 줄바꿈으로 이어 붙임 (멀티라인 유지)
- **제거 대상**: `메시지가 삭제되었습니다.` 줄, 빈 줄, 구분선만 있는 줄(`^[=\-_*\s]+$`)
- **출력 형식**: 각 메시지를 `[정리된이름] 본문` 한 블록으로 만들고 메시지 사이는 줄바꿈으로 연결

예)
```
[고지마제이] 네 맞습니다.
[그레포레] 감사합니다!
```

## UI 구성
- 상단 제목/간단 설명
- 좌측: 입력 textarea / 우측: 결과 영역 (모바일에선 위아래)
- 입력 시 `input` 이벤트로 실시간 변환
- "복사" 버튼 (결과 클립보드 복사), "지우기" 버튼
- 깔끔한 모던 스타일(카드 레이아웃, 적당한 여백)
